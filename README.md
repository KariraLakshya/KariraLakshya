## 🔨 What I've Built

**[CyberCortex](https://github.com/KariraLakshya/CyberCortex)** — Autonomous SOC analyst agent. A LangGraph agentic loop that processes security logs, reconstructs multi-stage attack chains, and maps behaviors to 13 MITRE ATT&CK techniques across on-premise and AWS environments, iterating until confidence exceeds 70%. Includes a cross-environment correlation engine for lateral-movement detection, VirusTotal reputation checks, automated AWS remediation, and a ChromaDB RAG pipeline that self-updates after each resolved investigation. Stack: LangGraph, Elasticsearch, AWS CloudTrail, MITRE ATT&CK, FastAPI, Next.js.

**[Self-Healing Sandbox](https://github.com/KariraLakshya/Self-Healing-SandBox)** — Autonomous QA agent that converts GitHub bug reports into executable Playwright test scripts and self-heals broken selectors via Gemini Vision AI in a closed feedback loop, with E2B sandboxed execution and Redis session management. Stack: Gemini 2.5, E2B, Playwright, FastAPI, React, Redis.

**[SneakerFever](https://sneakerfever.store)** — Production e-commerce store with Razorpay payment webhooks, Shiprocket logistics API, Sanity CMS, and MongoDB. Built and deployed end-to-end with Next.js + TypeScript.
